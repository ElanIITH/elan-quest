# Nexus Quest Website

**Official website:** [quest.elan.org.in](https://quest.elan.org.in)

**Description:**
Nexus Quest is the official online portal for the Olympiad organized by **Elan & nVision**. This website provides participants with information, registration, event details, and results.

---

## Tech Stack

- **Frontend Framework:** Next.js 13+ (App Router)
- **Styling:** Tailwind CSS
- **Font Management:** Google Fonts (`Press_Start_2P` & `Raleway`)
- **Hosting:** Cloudflare
